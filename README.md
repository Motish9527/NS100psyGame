# NS100psyGame
# 牛馬再就業協會｜職場動物心理測驗

以「找到自己的職涯牧場」為主題的互動式職涯探索小測驗。玩家回答 12 道職場情境題後，可探索自己較常展現的職場特質，並取得可分享的結果。

## 立即體驗

正式網站部署完成後，請在這裡放上 Vercel 提供的公開網址。

## 測驗內容

- 12 道職場情境選擇題，約 3 分鐘完成。
- 六種職場動物：衝鋒牛、領山虎、遠見鷹、靈活豹、群戰狼、暖心犬。
- 每個選項對應一種職場動物；選擇次數最多者為主要結果。
- 若最高分有多種動物並列，結果會呈現特質組合。
- 支援重新作答與分享結果。
- 支援手機與桌面瀏覽器；無需安裝套件或建置步驟。

## 在電腦上預覽

下載或複製專案後，直接用瀏覽器開啟根目錄的 `index.html` 即可遊玩。

## 部署到 Vercel

本專案是靜態網頁，沒有建置指令或伺服器需求。

1. 將 `index.html` 放在 GitHub 儲存庫根目錄並提交。
2. 登入 [Vercel](https://vercel.com/)，選擇 **Add New → Project**，匯入 GitHub 儲存庫 [`Motish9527/NS100psyGame`](https://github.com/Motish9527/NS100psyGame)。
3. 保留預設靜態網站設定；若需要選 Framework Preset，選 **Other**。不需設定 Build Command，輸出目錄使用專案根目錄。
4. 按下 **Deploy**。完成後即可使用 Vercel 提供的網址分享測驗。
5. 將新版本推送到 Vercel 設定的正式分支（通常是 `main`），Vercel 會自動重新部署。

## 更新網站

修改 `index.html` 後，提交並推送到 GitHub：

```bash
git add index.html
git commit -m "Update quiz"
git push
```

若正式分支已連結 Vercel，推送完成後會自動部署。GitHub 上的檔案也可透過 **Add file → Upload files** 上傳；請確認 `index.html` 位於儲存庫根目錄。

## 隱私與測驗說明

- 作答、計分與結果都在玩家自己的瀏覽器中處理。
- 本原型不會將答案或個人資料傳送至伺服器，也沒有資料庫或參與統計功能。
- 測驗為趣味職涯探索工具，不是經過心理計量驗證的專業人格測驗或心理診斷，也不應用於招募篩選或判定個人適合的職業。
